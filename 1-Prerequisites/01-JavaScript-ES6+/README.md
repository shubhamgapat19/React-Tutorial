# JavaScript ES6+ Fundamentals

## Why This Matters for React
React heavily uses ES6+ features. Understanding these concepts is crucial before learning React.

## Topics

1. **Arrow Functions** - Concise function syntax, lexical `this`
2. **Destructuring** - Extract values from arrays/objects
3. **Spread/Rest Operators** - Copy arrays/objects, handle function parameters
4. **Promises** - Handle asynchronous operations
5. **Async/Await** - Cleaner async code
6. **Modules** - Import/export code between files
