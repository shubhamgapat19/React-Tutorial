# ES6 Modules Examples

## Structure
This folder demonstrates various module patterns used in modern JavaScript and React.

## Files
- `math-utils.js` - Named exports example
- `User.js` - Default export (class)
- `constants.js` - Constants export
- `helpers.js` - Mixed exports
- `app.js` - Importing and using modules

## Running the Code
Since modules require a module system or bundler, you have options:

### Option 1: Node.js (add "type": "module" to package.json)
```bash
node app.js
```

### Option 2: Browser (use type="module")
```html
<script type="module" src="app.js"></script>
```

### Option 3: Bundler (Vite, Webpack)
Modern build tools handle this automatically.
