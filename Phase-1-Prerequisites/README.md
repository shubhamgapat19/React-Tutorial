# Phase 1: Prerequisites (1-2 weeks)

## Overview
Building a strong foundation in JavaScript ES6+, HTML5/CSS3, and Git before diving into React.

## Learning Goals
- ✅ Master modern JavaScript features
- ✅ Understand semantic HTML and modern CSS layout systems
- ✅ Get comfortable with version control

## Topics Covered

### 1. JavaScript ES6+ (Week 1)
- Arrow functions
- Destructuring
- Spread/Rest operators
- Promises
- Async/Await
- ES6 Modules

### 2. HTML5 & CSS3 (Week 1-2)
- Semantic HTML elements
- Flexbox layout
- CSS Grid
- Responsive design principles

### 3. Git & GitHub (Week 2)
- Git basics (init, add, commit, push)
- Branching strategies
- Pull requests and code reviews
