# Phase 7: DSA & Problem Solving for Frontend

## Overview
Data structures, algorithms, and JavaScript coding challenges specifically relevant to frontend interviews at top companies.

## Topics

| # | Topic | Focus |
|---|-------|-------|
| 1 | Data Structures | Arrays, HashMaps, Stacks, Queues, Trees, Graphs in UI context |
| 2 | Algorithm Patterns | Sliding Window, Two Pointers, BFS/DFS, Recursion, Dynamic Programming |
| 3 | JavaScript Coding Challenges | Polyfills, Utility Functions, Async Patterns, Event Systems |

## Why This Matters
- Top companies (FAANG, startups) test DSA even for frontend roles
- JavaScript-specific implementations differ from traditional DSA
- DOM traversal IS tree traversal — algorithms apply directly to UI work
- Understanding complexity helps build performant components

## Study Strategy
1. Learn the pattern → Understand when it applies
2. Solve 3-5 problems per pattern in JavaScript
3. Relate each pattern to a real frontend scenario
4. Time yourself — interviews give 20-45 min per problem

## Recommended Practice
- LeetCode (Easy → Medium, focus on Arrays/Strings/Trees)
- Frontend-specific: BFE.dev, GreatFrontEnd
- Daily: 1 DSA + 1 JS challenge
