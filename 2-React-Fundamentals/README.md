# Phase 2: React Fundamentals (2-3 weeks)

## Overview
Learn core React concepts - how to think in components, manage data with props and state, and build interactive UIs.

## Learning Goals
- Understand JSX and component architecture
- Pass data between components using props
- Manage local state with useState
- Handle user events
- Render dynamic lists and conditional UI
- Work with forms and controlled components
- Handle side effects with useEffect

## Topics Covered

### 1. JSX & Components
### 2. Props & Prop Drilling
### 3. State with useState
### 4. Event Handling
### 5. Conditional Rendering & Lists
### 6. Forms & Controlled Components
### 7. useEffect & Component Lifecycle
